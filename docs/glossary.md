# Glossary

- Editorial shell: layout with a persistent side panel, numbered sections, strong type hierarchy, and content presented like case studies.
- Sketch frame: image treatment using hard borders, slight rotation, overlay lines, and texture to make photos/screenshots feel drawn and intentional.
- CMS boundary: line between content edited in Payload and content derived in code from the CV or project title.
- Enrichment: code-side metadata added to an existing Payload project, such as year, role, stack tags, accent color, and metrics.
- Fallback content: polished default content used when Payload has no matching document yet.
